## Lead Stories

### Xodus is reverse-engineering the Xbox PC stack instead of waiting for Game Pass to support Linux

**New · Experiment**

Xodus can already authenticate with Xbox services, obtain game licenses, download MSIXVC packages and decrypt executables on demand. The remaining hard problem is runtime compatibility: reproducing enough Xbox Gaming Runtime behavior in Wine and related components for games to start correctly.

**Why it matters:** This is not another launcher skin. It targets proprietary identity, licensing, packaging and runtime services that Proton alone does not provide.

Source: https://github.com/xodus-gaming/xodus

### GoldenEye's completed decompilation is already turning into a native cross-platform game

**New · Experiment**

Goldeneye-Native compiles reconstructed GoldenEye 007 C directly for Windows, macOS and Linux, replacing N64 hardware interfaces with modern platform code. It already adds modern input, widescreen, high-refresh rendering, Lua mods, bots and experimental co-op.

**Why it matters:** Readable, rebuildable game logic makes problems that emulators can only work around from outside directly fixable in source.

Source: https://github.com/SegfaultEvan/goldeneye-native

### WeatherPaper gets year-scale battery life mostly by being awake for only seconds

**Emerging · Usable**

WeatherPaper is an ESP32-C3 weather display around a 4.2-inch e-paper panel and custom PCB. The project reports roughly 0.0494 mAh per refresh cycle and a 500-plus-day target from a 1500 mAh battery using deep sleep, an 80 MHz CPU clock and very short Wi-Fi sessions.

**Why it matters:** The useful mechanism is duty cycle: minimizing how long expensive subsystems are awake can matter more than making every active operation slightly cheaper.

Source: https://github.com/ngai-jeremy/WeatherPaper

### Agent oversight research is finding that better traces can save time without making humans more accurate

**Emerging · Experiment**

Human-computer interaction research found that ordinary agent action traces are cumbersome to verify. A redesigned oversight interface reduced time spent finding errors but did not meaningfully improve final verification accuracy; an August 24 position paper separately argues that agent use can erode the human skills oversight depends on.

**Why it matters:** A human approval button is not meaningful oversight unless the evidence, timing and reviewer expertise support real judgement.

Source: https://arxiv.org/abs/2602.16844

## How Did They Do That?

### How a tiny device gets a year of battery life: duty cycle

Average energy is current multiplied by time. WeatherPaper lets Wi-Fi be expensive for a few seconds, then spends almost all of its life in deep sleep; shortening setup by seconds can matter more than shaving milliamps from brief code.

Source: https://github.com/ngai-jeremy/WeatherPaper
